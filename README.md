## Baton

Baton is a shipped product: a backlog board that keeps a developer, a client and an
AI agent in one project, with the contract file doubling as the agent briefing so the
same document drives the UI and the work. It runs at [batonly.site](https://batonly.site),
and [manef.dev/catalog/baton](https://manef.dev/catalog/baton) is the catalogue entry.

## Repositori publik terpilih

- [Agent@Manef](https://github.com/official-manef/agent-at-manef): toolkit konteks agen dengan pendekatan satu sumber kebenaran.
- [MANEF Architecture](https://github.com/official-manef/manef-diagram): peta arsitektur, komponen dan panduan pengembangan, berjalan di [diagram.manef.dev](https://diagram.manef.dev).

Daftar di atas bersifat selektif, bukan daftar seluruh proyek. Dokumentasi masing-masing repositori merupakan rujukan teknis yang lebih mutakhir. Status implementasi, pengujian, dan penerimaan produksi tidak boleh dianggap sama.
